# 蝦皮分潤 — 請款、稅務與合規

_以 affiliate.shopee.tw 後台與官方幫助中心為準。這份是提醒自己每個月要做什麼。_

## 錢怎麼進來

```
下單 → 訂單完成 + 鑑賞期過 → 分潤「待確認」轉「已確認」
→ 每月 1 號產生上期對帳明細
→ 累積 ≥ NT$500（個人戶）→ 後台申請提領
→ 收到對帳單與勞報單 → 5 個工作日內回傳
→ 對帳單後 70 天內撥款（實務多在每月 25-27 日，遇假日順延）
```

| 項目 | 個人戶 | 公司戶 |
|------|--------|--------|
| 提領門檻 | NT$500 | NT$2,000 |
| 憑證 | 勞報單（蝦皮寄空白，填好回傳） | 發票 |
| 所得類別 | 92 其他所得，蝦皮代為申報 | 營業收入 |
| 單月分潤上限 | 達 NT$50,000（含）需轉公司戶 | 無 |

未達門檻會自動累積到下個月，不會消失。

## 每月 1 號要做的事

- [ ] 後台下載對帳明細，金額填進 `tracker.xlsx`「月結對帳」的「後台對帳金額」
- [ ] 核對「預估分潤」與「後台對帳金額」差異，差太多就查退貨
- [ ] 累積 ≥ 500 → 申請提領
- [ ] 收到勞報單 → 填好、簽名、5 個工作日內回傳；在表裡「勞報單已回傳」填 Y
- [ ] 入帳後填「入帳日」，累積未提領會自動歸零
- [ ] 把對帳單 PDF 存到自己的雲端，報稅時要對

## 稅務

### 所得稅
- 分潤是「92 其他所得」，蝦皮會主動申報，隔年 5 月報稅時會出現在所得清單。
- **一定要核對。** 2025 年有人被浮報 400 萬收入、稅金飆到 70 萬，靠自己留的對帳單才更正。對帳單一張都不要丟。
- 全年其他所得併入綜合所得稅計算，沒有特別扣除額。

### 營業稅（2026 年新規）
- 2026/05/15 起，推廣者要在後台完成「是否達課徵營業稅門檻」申報。
- 個人戶在蝦皮**單月**受領分潤達 NT$50,000（含）以上，需變更為公司戶，否則款項可能被卡。
- `tracker.xlsx`「月結對帳」的「營業稅警示」欄：單月 ≥ 40,000 變黃「接近 5 萬，提前準備」，≥ 50,000 變紅。看到黃色就開始準備，不要等紅色。

### 轉公司戶要準備什麼
- 行號或公司登記（最簡單是獨資行號，到地方政府商業登記辦）
- 統一編號、公司戶銀行帳號
- 到後台「公司戶供應商資訊提交」填資料
- 之後每次請款開發票給蝦皮，不再用勞報單

### 要不要一開始就用公司戶
不用。月分潤穩定超過 3 萬再評估。行號有記帳成本（每月記帳士約 2,000-3,000 元），分潤還小的時候不划算。

## 合規

### 不能推的商品
酒精飲料、菸草及相關、藥物藥品、電信電子監控設備、任何違法用途物品。

### 推了也拿不到分潤的品類
電子票券、捐贈類、服務類、遊戲點數等。選品時避開。

### 不能做的事
- 違法、色情、過度暴力、仇恨、歧視內容
- 商品描述加不相關品牌標籤
- 偽造訂單量、濫用購物金或折扣返還
- 自己用自己的連結買
- 洗板、在他人貼文下面貼連結
- 在社群上冒充蝦皮官方

### 處罰
第 1 次：警告並暫停所有分潤活動 → 第 2 次：凍結 7 天 → 第 3 次：凍結 28 天 → 第 4 次：永久停權。

### 每篇都要有的揭露
> 文內含蝦皮分潤連結，透過連結購買我會獲得少量回饋，不會影響你的價格。

這不只是平台要求，也是公平交易委員會對網路薦證廣告的揭露原則。寫清楚反而增加信任。

## 月結檢查清單（印出來貼在桌前）

```
□ 對帳明細下載、金額填表
□ 預估 vs 後台差異 < 10%
□ 申請提領（≥ 500）
□ 勞報單 5 個工作日內回傳
□ 對帳單 PDF 存雲端
□ 看營業稅警示欄顏色
□ 看創作者等級有沒有變
□ 檢查萬粉資格（任一社群 ≥ 10K）
```
