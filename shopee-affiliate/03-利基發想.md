# 蝦皮分潤 — 利基發想與選品

## 發想方法

我用四個問題篩方向，每個 1-5 分，再加權排名（權重與分數在 `niches.json`，跑 `make shopee-niches` 重算）：

1. **市場需求**：Threads / IG 上有沒有人在搜、在問、在抱怨這類東西？
2. **分潤率 / 加碼**：這類商品在後台常不常出現 10% 加碼？客單價 × 分潤率有沒有機會接近 NT$500 上限？
3. **低競爭**：是不是全網都在推？越多人推，7 天最後點擊歸因就越容易被搶走。
4. **內容好做**：在家用手機就能拍？還是要出門、要有小孩、要有車？
5. **回購 / 長尾**：買一次就結束，還是會一直回購？舊貼文會不會持續帶單？
6. **個人適配**：我自己真的會用、講得出缺點嗎？

## 選品檢查清單

每個進 `products.csv` 的商品都要過：

- [ ] 評價數 ≥ 500、評分 ≥ 4.7
- [ ] 蝦皮商城或後台標示「加碼」優先；一般賣場 1% 的要有很強的理由
- [ ] 價格帶 NT$300-2,000（低於 300 分潤太薄，高於 2,000 決策慢）
- [ ] 有免運或優惠券（降低 7 天內被別家搶走的機率）
- [ ] 賣家出貨速度快、聊聊回覆率高（退貨率低）
- [ ] 不是禁推品類（酒菸藥、電信監控、電子票券、服務類）
- [ ] 我自己買得起、願意買一個來拍（沒實拍可信度掉一半）
- [ ] 能用一句話講出它解決什麼痛點（填進 `pain_point` 欄）

## 怎麼找加碼商品

1. 後台「分潤加碼商品」專區，按分潤率排序。
2. 蝦皮 App 商品頁，有些會直接顯示「分潤 X%」。
3. 檔期前一週（雙 11、雙 12、超級品牌日、3.3、5.5、9.9），加碼商品清單會更新，先排 campaign 類型貼文。
4. 同一個賣家開了「賣家加碼」的，通常整間店都有，可以推整店。

## products.csv 欄位說明

| 欄位 | 填什麼 |
|------|--------|
| id | P001 起編 |
| niche | 對應 `niches.json` 的 id（home / desk / kitchen / money…） |
| category | 顯示用的分類名 |
| name | 商品名（寫你會講的名字，不是賣場標題） |
| price_twd | 售價 |
| est_commission_pct | 後台看到的分潤率（含加碼） |
| selling_points | 3 個賣點，用 `|` 分隔 |
| pain_point | 它解決的痛點，一句話 |
| target_audience | 受眾，一句話 |
| shopee_url | 商品原始網址（腳本會清成標準格式） |
| affiliate_link | 後台產生的 s.shopee.tw 短連結，產生後填回來 |
| sub_id | 留空，腳本會算 |
| status | idea → ready → live → paused |
| notes | 備註 |
