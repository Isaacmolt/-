# 蝦皮分潤 — 起床操作指南

## 現在的狀態

✅ 2026 制度研究完成（分潤比例、7 天歸因、分級制度、5 萬稅務門檻）
✅ 定位與 90 天路線圖
✅ 12 個利基方向評分，選定「租屋收納 + 辦公桌 3C」主線
✅ 5 種 Threads 模板、IG 模板、短影音分鏡
✅ 連結批次表 + 好物清單頁產生器
✅ 貼文草稿產生器 + 30 天排程
✅ 7 分頁營運追蹤表（含提領門檻、5 萬警示、KPI 儀表板）
✅ 收入模型計算器

❌ 還沒有：蝦皮分潤帳號、真實商品、真實連結、Threads 帳號

## 第一天（約 2 小時）

### 1. 申請（10 分鐘，之後等審核 1-3 天）
- 手機打開蝦皮 App → 我的 → 蝦皮分潤計畫 → 申請
- 或電腦到 https://affiliate.shopee.tw
- 選個人戶、綁定 IG / FB、推廣方式一定要填
- 社群帳號先設公開

### 2. 開帳號（20 分鐘）
- Threads + IG 同名，建議「小資效率實驗室」或自己想的名字
- 簡介照 `04-內容SOP.md` 的格式寫
- 先不放連結，等清單頂部署好

### 3. 設定（5 分鐘）
```bash
cp shopee-affiliate/config.example.json shopee-affiliate/config.json
```
把 `account_name`、`handle`、`tagline` 改成自己的。

### 4. 選品（60 分鐘，最重要）
打開蝦皮，照 `03-利基發想.md` 的選品檢查清單，找 12 個真實商品：
- 租屋收納 4 個、辦公桌 3C 4 個、廚房小家電 2 個、記帳文具 2 個
- 優先找後台有「加碼」標示的
- 每個商品把網址、價格、分潤率、3 個賣點、痛點填進 `shopee-affiliate/products.csv`

### 5. 跑一次（1 分鐘）
```bash
make shopee-all
```
會得到批次表、84 份草稿、30 天排程、追蹤表。

## 審核通過那天（30 分鐘）

1. 打開 `shopee-affiliate/reports/link-batch.csv`
2. 到後台「商品連結產生器」，每一列：貼 canonical_url → 填 sub_id → 取得短連結
3. 短連結填回 `products.csv` 的 `affiliate_link`，status 改 `ready`
4. 再跑 `make shopee-links`，清單頁就會有商品
5. 清單頁網址放到 Threads / IG 個人檔案（部署後在 GitHub Pages 的 `/shopee-affiliate/linkpage/`）
6. 發第一篇：`shopee-affiliate/posts/P001/threads_pain_point.txt`，改成自己口氣，連結放留言

## 之後每天（30-45 分鐘）

```
早上：看 reports/content-calendar.md 今天排什麼 → 改草稿 → 發 Threads 1 篇
晚上：發 Threads 1 篇 + IG 1 篇 → 回留言 → 後台數字填進 tracker.xlsx 每日數據
```

每週日跑一次週檢討（`04-內容SOP.md`），每月 1 號對帳（`05-請款稅務與合規.md`）。

## 90 天檢查點

| 天 | 看什麼 | 沒達到怎麼辦 |
|----|--------|-------------|
| 14 | 有任何一篇觸及 > 1,000？有第一筆點擊？ | 改鉤子和首圖，不換主題 |
| 30 | 後台待確認分潤 > 0？累積點擊 > 300？ | 換選品，找加碼商品 |
| 60 | 月分潤 ≥ 1,000？追蹤者 ≥ 500？ | 開始做短影音 |
| 90 | 月分潤 ≥ 5,000？ | < 2,000 檢討定位；> 5,000 考慮第二帳號 |

## 有問題？
