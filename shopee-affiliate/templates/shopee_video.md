# 短影音腳本模板（蝦皮影音 / Reels / Shorts 通用）

長度 15-30 秒。手機直拍 9:16，第一秒一定要有畫面變化或字卡。
蝦皮影音的分潤要在影片裡「掛商品」，上傳時記得選商品。
可用變數同 threads.md。

### demo_15s｜15 秒實測
【0-2 秒 鉤子】
字卡：{pain_point}？
畫面：直接拍問題的現場（亂的桌面 / 塞爆的衣櫃 / 痠痛的動作）

【2-10 秒 解法】
字卡：{name}
畫面：拿出商品 → 安裝或使用 → 立刻看到結果
旁白/字卡：{sp1}，{sp2}

【10-13 秒 補一刀】
字卡：{sp3}
畫面：細節特寫（材質 / 承重 / 開關）

【13-15 秒 CTA】
字卡：NT${price}，連結在商品卡 👇
畫面：成品定格

備註：{disclosure}

### compare_30s｜30 秒對比
【0-3 秒】字卡：「以前 vs 現在」｜畫面：左右分割或先拍以前
【3-12 秒】以前：{pain_point}（拍 2-3 個真實困擾畫面）
【12-24 秒】現在：{name}，{sp1}、{sp2}、{sp3}（每個賣點配一個畫面，各 4 秒）
【24-27 秒】真心話：說一個小缺點，再說為什麼還是推
【27-30 秒】CTA：NT${price}，{audience}可以試試，商品連結在下面 👇

備註：{disclosure}
