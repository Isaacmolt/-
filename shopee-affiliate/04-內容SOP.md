# 蝦皮分潤 — 內容 SOP

## 帳號設定

| 項目 | 做法 |
|------|------|
| 名稱 | Threads 與 IG 同名，中文 + 好記，例：小資效率實驗室 |
| 簡介 | 一句定位 + 一句可信度 + 一句 CTA。例：「租屋族的省錢 × 效率好物實測｜每樣都自己買來用｜好物清單 👇」 |
| Bio 連結 | 放 `linkpage/index.html` 部署後的網址（好物清單頁），不要直接放單一商品連結 |
| 頭貼 | 真人照或固定視覺，不要用商品圖 |
| 置頂 | 一篇「我是誰、這個帳號在做什麼、怎麼找我推過的東西」 |

## Threads 貼文公式

```
鉤子（第一行，決定 80% 觸及）
痛點（讀者的處境，不是商品）
解法（商品名 + 價格）
證據（3 個賣點或 1 個實測數字）
真心話（1 個缺點）
CTA（連結在留言）
揭露
```

規則：
- 單篇 500 字上限，寫 150-300 字最好。
- **連結放第一則留言**，主文不放連結（主文有外連觸及會被壓）。
- 第一張圖要有「對比」或「結果」，不要放賣場主圖。
- 每篇只推一個商品。清單文最多 3 個，而且要同一個情境。
- 每天 2 篇：早上 8-9 點、晚上 9-11 點。
- 發完 30 分鐘內回完所有留言，演算法很吃早期互動。
- 一天內不要連發 3 篇以上帶連結的文。

### 五種類型與用途

| 類型 | 用途 | 排程比例 |
|------|------|---------|
| 痛點共鳴 | 拉新觸及，最容易被推 | 30% |
| 前後對比 | 高轉換，需要實拍 | 20% |
| 一句話推薦 | 填充日常，省時間 | 20% |
| 清單文 | 拉收藏與追蹤 | 20% |
| 檔期提醒 | 只在活動期發，轉換率最高 | 10%，活動期拉到 40% |

草稿由 `scripts/shopee_post_generator.py` 從 `templates/threads.md` 產生，**一定要改成自己的口氣再發**。模板的鉤子是通用版，發之前至少換掉第一行。

## 短影音腳本（15-30 秒）

結構：鉤子（0-2 秒）→ 解法（2-10 秒）→ 補一刀（10-13 秒）→ CTA（13-15 秒）。完整分鏡在 `templates/shopee_video.md`。

拍攝清單：
- 手機直拍 9:16，開格線
- 自然光或一顆桌燈，不要背光
- 先拍「問題現場」再拍「解決後」，剪在一起就是前後對比
- 商品細節特寫至少 1 個（材質、承重、開關）
- 字卡用 App 內建就好，字要大

同一支影片三個地方用：蝦皮影音（掛商品拿分潤 + 衝等級）、IG Reels（文案在 `templates/instagram.md`）、Threads（附短連結）。

## IG 輪播結構

| 張數 | 內容 |
|------|------|
| 1 | 標題卡：痛點一句話 + 商品名 |
| 2-4 | 每張一個賣點，配實拍 |
| 5 | 缺點 + 適合誰 |
| 6 | CTA：連結在個人檔案好物清單 |

IG 貼文不能放外連，所以一律導到 Bio 的清單頁。

## 揭露與合規

每篇都加（已經寫在 config 的 `disclosure`）：
> ✨ 文內含蝦皮分潤連結，透過連結購買我會獲得少量回饋，不會影響你的價格。

不做的事：
- 不講療效、不講「保證」「最便宜」
- 不用賣場的圖當自己的實拍
- 不把別人的開箱影片剪來用
- 不貼不相關的品牌 hashtag
- 不用自己的連結買東西
- 不在別人貼文下面洗連結

## 每日工作流程

```
1. 打開 reports/content-calendar.md，看今天排了什麼
2. 打開對應的 posts/<ID>/<平台>_<類型>.txt，改成自己的口氣
3. 到 affiliate.shopee.tw 後台 → 商品連結產生器 → 貼商品網址 + sub_id（照 schedule.csv）→ 取得短連結
4. 發文，連結放第一則留言
5. tracker.xlsx「貼文日誌」登記：日期、平台、類型、商品 ID、sub_id、貼文網址
6. 晚上：後台「報表」看今天點擊/訂單 → 填進「每日數據」
```

## 每週檢討（週日 45 分鐘）

打開 `tracker.xlsx`「KPI 儀表板」和「貼文日誌」，回答四個問題：

| 問題 | 看哪裡 | 怎麼做 |
|------|--------|--------|
| 哪種類型觸及最好？ | 貼文日誌「觸及」依類型排序 | 下週排程往那種傾斜 |
| 哪個商品有點擊沒訂單？ | 後台報表依 sub_id 篩 | 價格或評價有問題，換同類商品 |
| 哪個商品零點擊？ | 後台報表 | 30 天零點擊就改 status = paused |
| 加碼商品有沒有新的？ | 後台加碼專區 | 加 3-5 個進 products.csv |

然後重跑 `make shopee-posts` 產生下週排程。

## 數據怎麼判讀

| 現象 | 大概原因 | 先改什麼 |
|------|---------|---------|
| 觸及低（< 200） | 鉤子弱、第一張圖沒對比 | 改第一行與首圖，不要換主題 |
| 觸及 OK 但點擊率 < 1% | 內容沒讓人想買、CTA 不清楚 | 加痛點、加價格、CTA 改「連結在留言」 |
| 點擊 OK 但轉換率 < 2% | 商品頁評價差、價格比別家高、沒免運 | 換商品 |
| 轉換 OK 但每單分潤 < 15 元 | 分潤率太低或客單太低 | 換加碼商品或高單價品 |
| 待確認分潤一直沒轉已確認 | 鑑賞期或退貨 | 等 15 天；退貨率高就換商品 |
