# 蝦皮分潤 — 內容 SOP

## 帳號設定

| 項目 | 做法 |
|------|------|
| 名稱 | Threads 與 IG 同名，中文 + 好記，例：小資效率實驗室 |
| 簡介 | 一句定位 + 一句可信度 + 一句 CTA。例：「租屋族的省錢 × 效率好物實測｜每樣都自己買來用｜好物清單 👇」 |
| Bio 連結 | 放 `linkpage/index.html` 部署後的網址（好物清單頁），不要直接放單一商品連結 |
| 頭貼 | 真人照或固定視覺，不要用商品圖 |
| 置頂 | 一篇「我是誰、這個帳號在做什麼、怎麼找我推過的東西」 |

## Threads 貼文公式

原則只有一條：**看起來不能像廣告。** 像廣告的文會被演算法壓，也會被讀者直接滑掉。

```
第一行：觀點或爭議句（口語，像跟朋友嗆聲或抱怨）
中段：自己的情境、怎麼踩雷、怎麼解；商品名隨口提到一次
結尾：一個真實缺點，或丟一個問題讓人想回
```

主文不放的東西：價格、連結、「連結在留言」、揭露、賣點條列、emoji 箭頭。
放在第一則留言的東西：分潤連結 + 一句揭露（「這是蝦皮分潤連結，用它買我會拿到一點回饋，你的價格不變」）。主文發完立刻回這則。

每個商品都要先想好一句「爭議句」填進選品庫的 hot_take 欄（應用裡叫「爭議句 / 反直覺觀點」）。沒有這句，模板出來的文會很平。好的爭議句長這樣：
- 租屋族買收納用品九成都是在交智商稅
- 肩頸痠去按摩是治標，問題是你的螢幕太低
- 一個人住買大氣炸鍋的，最後都變成置物架

規則：
- 單篇 500 字上限，寫 80 到 200 字最好，越像隨手打的越好。
- 每天 2 篇：早上 8 到 9 點、晚上 9 到 11 點。
- 發完 30 分鐘內回完所有留言，有人問「哪裡買」就回連結那則留言。
- 一天內不要超過 3 篇帶商品的文；中間穿插純觀點、純抱怨、純生活的文，比例大約 1 篇商品配 1 篇沒商品。
- 第一張圖要是自己拍的現場，不要賣場圖。

### 六種類型與用途

| 類型 | 用途 | 排程比例 |
|------|------|---------|
| 反直覺觀點 | 拉新觸及，最容易被推 | 30% |
| 抱怨文 | 引留言，最像真人 | 20% |
| 真心話 | 高轉換，靠「缺點」建立可信度 | 15% |
| 丟問題 | 引留言，把人帶進連結所在的留言區 | 15% |
| 前後對比 | 需要實拍，轉換高 | 10% |
| 檔期提醒 | 只在活動期發 | 10%，活動期拉到 30% |

草稿由應用的「貼文」頁或 `scripts/shopee_post_generator.py` 從 `templates/threads.md` 產生，**一定要改成自己的口氣再發**，特別是第一行。

## 短影音腳本（15-30 秒）

結構：鉤子（0-2 秒）→ 解法（2-10 秒）→ 補一刀（10-13 秒）→ CTA（13-15 秒）。完整分鏡在 `templates/shopee_video.md`。

拍攝清單：
- 手機直拍 9:16，開格線
- 自然光或一顆桌燈，不要背光
- 先拍「問題現場」再拍「解決後」，剪在一起就是前後對比
- 商品細節特寫至少 1 個（材質、承重、開關）
- 字卡用 App 內建就好，字要大

同一支影片三個地方用：蝦皮影音（掛商品拿分潤 + 衝等級）、IG Reels（文案在 `templates/instagram.md`）、Threads（附短連結）。

## IG 輪播結構

| 張數 | 內容 |
|------|------|
| 1 | 標題卡：痛點一句話 + 商品名 |
| 2-4 | 每張一個賣點，配實拍 |
| 5 | 缺點 + 適合誰 |
| 6 | CTA：連結在個人檔案好物清單 |

IG 貼文不能放外連，所以一律導到 Bio 的清單頁。

## 揭露與合規

Threads 的揭露放在第一則留言，跟連結在一起（已經寫在 config 的 `disclosure`）；IG 和短影音放在文案尾端：
> 這是蝦皮分潤連結，用它買我會拿到一點回饋，你的價格不變。

不做的事：
- 不講療效、不講「保證」「最便宜」
- 不用賣場的圖當自己的實拍
- 不把別人的開箱影片剪來用
- 不貼不相關的品牌 hashtag
- 不用自己的連結買東西
- 不在別人貼文下面洗連結

## 每日工作流程

```
1. 打開 reports/content-calendar.md，看今天排了什麼
2. 打開對應的 posts/<ID>/<平台>_<類型>.txt，改成自己的口氣
3. 到 affiliate.shopee.tw 後台 → 商品連結產生器 → 貼商品網址 + sub_id（照 schedule.csv）→ 取得短連結
4. 發文，連結放第一則留言
5. tracker.xlsx「貼文日誌」登記：日期、平台、類型、商品 ID、sub_id、貼文網址
6. 晚上：後台「報表」看今天點擊/訂單 → 填進「每日數據」
```

## 每週檢討（週日 45 分鐘）

打開 `tracker.xlsx`「KPI 儀表板」和「貼文日誌」，回答四個問題：

| 問題 | 看哪裡 | 怎麼做 |
|------|--------|--------|
| 哪種類型觸及最好？ | 貼文日誌「觸及」依類型排序 | 下週排程往那種傾斜 |
| 哪個商品有點擊沒訂單？ | 後台報表依 sub_id 篩 | 價格或評價有問題，換同類商品 |
| 哪個商品零點擊？ | 後台報表 | 30 天零點擊就改 status = paused |
| 加碼商品有沒有新的？ | 後台加碼專區 | 加 3-5 個進 products.csv |

然後重跑 `make shopee-posts` 產生下週排程。

## 數據怎麼判讀

| 現象 | 大概原因 | 先改什麼 |
|------|---------|---------|
| 觸及低（< 200） | 鉤子弱、第一張圖沒對比 | 改第一行與首圖，不要換主題 |
| 觸及 OK 但點擊率 < 1% | 內容沒讓人想買、CTA 不清楚 | 加痛點、加價格、CTA 改「連結在留言」 |
| 點擊 OK 但轉換率 < 2% | 商品頁評價差、價格比別家高、沒免運 | 換商品 |
| 轉換 OK 但每單分潤 < 15 元 | 分潤率太低或客單太低 | 換加碼商品或高單價品 |
| 待確認分潤一直沒轉已確認 | 鑑賞期或退貨 | 等 15 天；退貨率高就換商品 |
