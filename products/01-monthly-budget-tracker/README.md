# Product 01: Monthly Budget Tracker

## 產品規格

### 分頁結構
1. **Dashboard** — 月度總覽儀表板
2. **Monthly Input** — 每月收支輸入
3. **Categories** — 分類設定與預算上限
4. **Annual View** — 12 個月趨勢總覽
5. **Instructions** — 使用說明

### 核心公式
- SUMIFS 依分類加總支出
- 預算達成率 = 實際/預算
- 儲蓄率 = (收入-支出)/收入
- 條件格式：超支紅色、達標綠色

### 分類預設
需求 (50%): 房租, 水電, 交通, 食物, 保險
想要 (30%): 娛樂, 外食, 購物, 訂閱
儲蓄 (20%): 存款, 投資, 緊急預備金
