# SiteCraft 業務手冊（PLAYBOOK）

## 1. 商業模式

| 項目 | 內容 |
|---|---|
| 賣什麼 | 在地商家的一頁式官網：手機好看、有營業時間 / 地圖 / 一鍵撥號 / LINE，含 1 年主機 |
| 賣給誰 | Google 地圖上有店、有評論、但「網站」欄位是空的或只放 FB / IG / LINE 的店家 |
| 怎麼賣 | **先做再賣**：免費做好草稿寄給老闆看，看得到才會買 |
| 價格 | **NT$860 一次付清**，無月費（低於「要不要想一下」的心理門檻，等於一桌客人的消費） |
| 成本 | 主機 0（GitHub Pages）、API 0（免費額度內）、Claude 文案約 NT$0.3/站、時間約 10 分鐘/站 |
| 加購 | 專屬網域 500/年、第二年維護 600/年、菜單頁 300、LINE 官方帳號串接 300、Google 商家檔案優化 400（見 `config.json` → `upsells`） |

**數字怎麼算**：冷信回覆率抓 5%、回覆後成交一半 → 每 40 封成交 1 家。每天寄 30 封 ≈ 每週 5 家 ≈ **每週 NT$4,300**，加購與續約另計。一個月做 300 個示範站只要跑腳本，瓶頸在「找 email」和「回信」，所以手冊後面花最多篇幅講這兩件事。

## 2. 完整流程

```
find_leads ─→ build_site ─→ push ─→ 找 email ─→ send first ─┬→ 回覆 → 談 → 付款 → 收照片 → publish → push → 上線通知
                                                           ├→ 4 天沒回 → followup1
                                                           └→ 再 5 天沒回 → followup2 → 7 天 → sweep 結案
```

### 2.1 找商家（find_leads.py）
- 一次掃「一個行政區 × 一種類型」最準（例：`--city 台中市 --district 西區 --type 咖啡廳`）。Google 一組關鍵字最多回 60 家，所以用行政區拆開來掃才拿得到完整名單。
- 優先類型（最容易成交）：**美髮 / 美甲 / 寵物美容 / 按摩 / 早午餐 / 咖啡廳 / 補習班 / 牙醫**。這些店靠預約與回頭客、老闆在乎形象、客單價高到 860 不痛。
- 先避開：連鎖、夜市攤、評論 < 3 則（可能已歇業）、已有真官網的（程式自動標 `has_website`）。
- 「只有 FB 粉專」的店是最好的客人：他們已經知道線上曝光重要，只是沒人幫他做網站。

### 2.2 做網站（build_site.py）
- 示範版自動用主題預設文案；加 `--ai-copy` 會讓 Claude 依店名、類別、評分、營業時間寫專屬文案，成交率會高一點（老闆覺得「你真的有看我的店」）。
- 做完一定要**自己用手機開一次**再寄。
- 推上 GitHub 後網址才會生效，寄信前先確認 `demo_url` 打得開。

### 2.3 找 email 的 7 個地方（Google 地圖沒有 email）
1. **Facebook 粉專 →「關於」→ 聯絡資訊**：台灣小店最常把 email 放這裡。`leads.csv` 的 `website_uri` 常常就是粉專網址。
2. **Instagram 簡介**：商業帳號會有「電子郵件」按鈕（手機版才看得到）。
3. **Google 商家檔案本身**：有些店的「網站」是 linktr.ee / portaly 之類的連結頁，點進去找。
4. **店家菜單、名片、發票、DM**：很多會印 email；Google 地圖的照片裡常有菜單照（看，但不要下載來用）。
5. **徵才網站**：104、518、小雞上工搜店名，徵才聯絡人常是老闆本人的 email。
6. **經濟部商工登記公示**（findbiz.nat.gov.tw）：搜店名或負責人，公司登記有時有 email。
7. **直接打電話**：「老闆您好，我幫您做了一個網站草稿想寄給您看，方便留個 email 嗎？」八成會給。這其實是最快的方法，也等於第一次接觸。

找不到 email 的替代通道（示範網址一樣好用）：
- **LINE 官方帳號 / 粉專 Messenger** 私訊：把 `templates/email/01_first_touch.txt` 的內容縮成 5 行貼過去。
- **實體拜訪**：印一張小卡片（repo `card/` 有名片素材），放示範網站 QR code，下午 2～4 點客人少的時候去。當面成交率遠高於 email。

把找到的寫進去：`python sitecraft/crm.py email <slug> owner@shop.tw`、`crm.py contact <slug> --line https://lin.ee/xxx --fb ...`（FB / IG / LINE 填了會直接出現在網站上）。

### 2.4 寄信（send_outreach.py）
- **每天 20～30 封就好**，分早上 10 點和下午 3 點兩批。新信箱前兩週每天 10 封暖身。
- 永遠先 `--stage first`（不加 `--send`）預覽，打開 `outbox/*.eml` 看一眼再寄。
- 主旨不要有「免費」「優惠」「限時」；內文不放附件、不放圖片、連結只有一個（示範站）。
- 收到回信當天回；老闆通常晚上才看信，隔天早上一定要回到。
- 有人回「不用了」：`--opt-out 他的@email`，然後真的不要再寄。

### 2.5 成交與交付
1. 老闆說要 → 回信給付款方式（見 §4）→ 收到款 `crm.py won <slug>` → `send_outreach.py --stage after_payment --slug <slug> --send`
2. 收到照片：存到 `sitecraft/sites/<slug>/img/`（檔名用 `01.jpg`～`06.jpg`，先用手機截圖或線上工具壓到 300KB 以下），編輯 `sites/<slug>/content.json`：`gallery` 填檔名、改 `tagline` / `about` / `services`、補 LINE / FB / IG
3. `python sitecraft/build_site.py --slug <slug> --rebuild` → 手機開一次確認 → 把預覽傳給老闆確認
4. `python sitecraft/crm.py publish <slug>` → `git push` → 同一個網址，示範橫幅消失
5. `send_outreach.py --stage delivered --slug <slug> --send`（內含「怎麼把網址加進 Google 商家檔案」的 3 步驟）
6. 一週後追問一句「網站有沒有幫上忙？」順便請他介紹隔壁店（介紹成功送一次免費更新）

## 3. 話術與異議處理

**自我介紹（電話 / 當面）**
「老闆您好，我是在幫{區}的店家做網站的，我看到您在 Google 地圖上評價很好但還沒有官網，就先幫您做了一個，您用手機掃一下看看，不喜歡沒關係。」

| 老闆說 | 回法 |
|---|---|
| 我有 FB 就夠了 | 「FB 很好，網站是放在 Google 地圖『網站』按鈕裡的那一個。客人搜到您，點一下就看到營業時間和 LINE，不用登入 FB、不會被演算法藏起來。而且我把您的 FB 也放在網站上，兩邊都有。」 |
| 太貴 / 沒預算 | 「860 是一次付清，沒有月費，一年主機都含在裡面，等於一桌客人。其他家做網站都是幾萬起跳還要年費。」 |
| 我不會用電腦 | 「您完全不用碰，照片用 LINE 傳給我就好，之後要改營業時間也是傳訊息給我。」 |
| 我再想想 | 「好，草稿我會留 7 天，您隨時用手機看。我禮拜四再問您一次就好。」（記 `crm.py note`，到期真的再問一次） |
| 你們是誰？可信嗎？ | 給作品集網址 `https://isaacmolt.github.io/-/sites/` + 名片 + 先做好才收費。「您看到滿意才付，付完才正式上線。」 |
| 可以不要放你們的名字嗎 | 可以。`config.json` → `show_credit_on_final_site: false` 或單獨在 content 裡拿掉。 |
| 要有自己的網址 | 加購 500/年，含設定。或教他自己買網域（Namecheap / Gandi）我們幫設。 |
| 要放菜單 / 價目表 | 加購 300，或 30 個品項內放進 services 直接做。 |

## 4. 收款

- **銀行轉帳**（最通用）：回信附帳號 + 「轉帳後截圖給我即可」。
- **LINE Pay / 街口** 個人收款碼：老闆最熟。
- **現金**：當面成交時。
- 一律收到款再 `crm.py won`，付款前就已經做好的草稿是我們的成本，不要先交付正式版。
- 稅務提醒：依財政部規定，個人以勞務為業每月銷售額達 NT$40,000 以上需辦理稅籍登記；超過門檻請諮詢會計師或改以工作室 / 行號名義經營。這不是法律意見，請以主管機關公告為準。

## 5. 法律與平台規範（一定要遵守）

1. **Google Places API 條款**：我們只用官方 API，不爬 Google 地圖網頁。API 回來的**照片與評論文字不能存、不能放到別人的網站**，示範版因此用示意圖；評分數字與連回 Google 地圖的連結可以。店家名稱、地址、電話屬公開商業資訊。
2. **個資法**：店家公開的商業聯絡方式用於商業聯繫原則上可行，但每封信都要有寄件人身分、停止寄送的方式，且一說不要就要停（程式已內建 `opted_out` 永不再寄）。不要把名單賣給別人或拿去做別的用途。
3. **不要冒充**：不要說「Google 合作夥伴」「Google 通知您」；寄件人就是你自己的工作室名。
4. **寄信量**：Gmail 個人帳號 500 封/天是技術上限，不是目標。冷信維持每天 ≤ 30、每封個人化，被標垃圾信一次要修很久。
5. **著作權**：正式版只放老闆自己提供或授權的照片；文案由我們寫、交付後歸店家。
6. **字型**：Noto Sans TC / Noto Serif TC / Fraunces / Syne / Space Grotesk 都是 SIL Open Font License，可商用、可切子集再散布；建站時會切好放在每個站的 `fonts/` 裡，交付包不用另外處理。

## 6. 每週檢視的數字

| 指標 | 目標 | 怎麼看 |
|---|---|---|
| 新示範站 / 週 | 100 | `crm.py stats` → demo_ready 以上 |
| 找到 email 比例 | ≥ 50% | `crm.py list --status demo_ready --no-email` |
| 寄出 / 週 | 150 | `data/sent_log.csv` |
| 回覆率 | ≥ 5% | `crm.py stats` |
| 成交 / 週 | 4～6 | `crm.py stats` → won + delivered |
| 交付天數 | ≤ 3 | `paid_at` → `publish` |
| 加購率 | ≥ 30% | 自己記在 `notes` |

回覆率低於 3%：換主旨、換第一句、檢查示範站是不是真的打得開、換一個類型的店試。
成交率低但回覆率正常：價格不是問題，是信任——多放作品集、多用電話 / 當面。

## 7. 一個月的節奏

| 週 | 做什麼 |
|---|---|
| 第 1 週 | 設定好 API 與 Gmail；掃 3 個行政區 × 5 種類型；做 100 個示範站；每天 10 封暖身 |
| 第 2 週 | 每天 25 封 + 追蹤信；第一批回覆進來；完成前 3 個正式站（拿來當作品集） |
| 第 3 週 | 固定節奏；開始電話 / 到店補強 email 找不到的店；試 `--ai-copy` 看成交率差異 |
| 第 4 週 | 看數字調整類型與區域；對已交付客戶推加購；請他們介紹鄰居 |
