# SiteCraft 品質閘門（qa/）

品質標準以 Awwwards、Webby Awards、FWA 獲獎作品為目標。每次改 `templates/site/onepage.html.j2`
或 `build_site.py` 之後，重新產生網站並跑這個閘門；全部 PASS 才算完成。

```bash
cd sitecraft/qa
npm install && npx playwright install chromium      # 只需一次
python ../build_site.py --sample                       # 重新產生三個範例站
python make_fixture.py                                 # 測試站 sites/_qa-photos/（有照片）與 sites/_qa-edge/（邊界案例），不進 git、不部署
node qa.js demo-cafe,demo-hair,demo-pet,_qa-photos,_qa-edge 回合名稱
```

範例站沒有照片，所以另外建一個「有照片」的測試站，燈箱、照片圖說與 `img/` 路徑才會被測到；
`_qa-edge` 是長店名、午晚兩段營業、營業到凌晨、沒有評分、沒有 LINE、粗獷字型語氣的組合。

每個站點檢查：
- 桌機 1440×900、筆電 1366×768、手機 390×844 截圖（首屏、整頁、選單、深色模式）
- axe-core（WCAG 2.1 AA + best-practice）在桌機與手機、亮色與深色模式皆為 0 違規
- 無橫向溢出；所有可點元素至少 44px；整頁零 emoji；無 console / page error
- hero 區塊高度恰好等於示範橫幅以上的可視範圍（三種尺寸）
- 功能：首屏不顯示快速列、漢堡按鈕可開可關、選單是真正的對話框（焦點進入且困在裡面）、
  相簿上一張／下一張與計數器正確、服務列可用鍵盤聚焦、標題第二行無縮排、資訊列不截字
- 計算樣式：h1 真的套用展示字型（Fraunces / Syne）且與內文不同、網頁字型已載入、
  相簿磚比例 4:3 與 3:4、有 og:image
- 相簿：滑鼠拖曳不會開燈箱、計數器走到最後一張且「下一張」停用、從最後一張按「上一張」會移動；
  只有照片磚能開燈箱，燈箱置中；hero 資訊列的電話與地址是連結；大標兩段各自不被拆開
- 動態：hero 圖騰每一筆都畫完（含休息中狀態）、減少動態時不跑描線動畫
- 筆電扣掉瀏覽器工具列（1366×657、1536×730、1440×789）與最小手機（320×568）首屏也放得下；手機上沒有圖案壓在首屏按鈕後面；
  藏起來的快速聯絡鈕不能用 Tab 選到；所有類別都有場景插畫、所有強調色在深色底上對比 4.5 以上
- 短手機（360×640、375×667）首屏不被示範橫幅蓋到；橫向手機（844×390）選單可捲動、按鈕碰得到；地圖卡的圖釘不壓到地址；
  有照片時首屏照片在手機上滿版、關於我們有第二張照片
- 字型：自架字型全部載入成功
- 橫向手機（844×390）首屏按鈕不被示範橫幅蓋到；選單的店名不壓到關閉鈕、按鈕不論幾個都填滿一列；
  營業燈號對齊第一行文字中線；圖騰閒置漂移不超過 20px；價目表的虛線從品名連到價格；深色模式快速聯絡鈕有亮邊；
  關燈箱後焦點回到最後看的那張照片
- 手機首屏的營業狀態行不被示範橫幅蓋到；大標字級不會在大螢幕反而變小；導覽列店名在手機上不被截斷；首屏照片拱門不碰到導覽列；
  平板上的首屏照片與關於我們插畫是 4:3；招牌卡按鈕的焦點框看得到；有照片的站示範橫幅不說「換上您的照片」；
  相簿直排磚的店名不截字；沒有照片時相簿是三張場景插畫、店面招牌的店名放得進招牌；手機上快速聯絡鈕在服務列經過時讓開；
  結尾插畫在手機上也不壓到按鈕；`_qa-edge` 週一中午不會出現「今晚」
- 首屏沒有任何資訊格被示範橫幅切成兩半；導覽列捲動 40px 就是實底；相簿捲到底後往回甩會回去；沒有 LINE 的站招牌卡按鈕不寫 LINE；
  `_qa-edge` 週四 15:00（17:00 開門）結尾大標是「晚點…」，週六凌晨 1:00 仍是「今晚…」
- 900×800 也檢查：導覽連結與電話不換行；手機上分兩段的營業時間不多出空行；範例咖啡週日晚上結尾大標寫「週二」
- 每個尺寸的服務列都不溢出、價格不壓到詢問按鈕；手機直排字至少 14px；休息中時結尾插畫只少了蒸氣，其他筆畫都在；
  畫完的線條沒有虛線接縫；鍵盤聚焦在導覽列時導覽列會出現；三張的相簿在桌機不需要捲動
- 相鄰區塊底色不同；每一列服務都標明 LINE／電話詢問；快速聯絡鈕有導航；橫幅版型首屏插畫在桌機（高 700 以上）至少 140px 高
- 營業時間用固定的台北時間驗證：範例咖啡週日晚上顯示「週二 10:00 開門」（週一公休）；
  `_qa-edge` 週日凌晨 1:30 標出週六那列（「現在」）並顯示「營業中 02:00 打烊」
- Lighthouse 行動版：效能、無障礙、最佳做法、SEO 都要 90 以上

輸出：`qa/shots/<回合>/` 內有截圖與 `report.json`。
接著把截圖交給一位「不知道你結論」的評審，用六項指標（視覺、創意、內容層級、易用性、互動、工藝）
各打 1～10 分；每項 8 以上且平均 8.5 以上才算達標，否則依修正清單再做一輪。
