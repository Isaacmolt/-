# SheetCraft AI — Canva 產品展示圖設計指南

## 品牌設計系統

### 色彩
- **主色（背景）**: #2D5F2D (深綠)
- **輔色（卡片底）**: #F5F0E8 (米白)
- **強調色（CTA）**: #D4A574 (金棕)
- **文字色**: #1A1A1A (近黑)
- **白色**: #FFFFFF

### 字體
- **標題**: Montserrat Bold, 32-48px
- **副標題**: Montserrat Semi-Bold, 20-24px
- **內文**: Open Sans Regular, 14-16px
- **標籤/小字**: Open Sans Light, 10-12px

---

## Etsy 圖片規格

- **尺寸**: 2700 x 2025 px (4:3 比例)
- **最多**: 10 張圖片
- **格式**: PNG 或 JPG
- **第一張是主圖** — 這張決定點擊率

---

## 每個產品需要的 5 張必備圖

### 圖 1: 主圖 (Hero Image)
**佈局：**
- 深綠背景
- 中央放模板截圖（帶陰影，稍微傾斜 5 度增加動態感）
- 頂部：產品名稱（白色大字）
- 底部：「Google Sheets Template | Instant Download」
- 右上角：金棕色價格標籤

**Canva 步驟：**
1. 新建 2700x2025px 設計
2. 背景色 #2D5F2D
3. 上傳模板截圖 → 加白色邊框 → Drop Shadow
4. 加標題文字 (Montserrat Bold, White, 48px)
5. 加副標 (Open Sans, #D4A574, 20px)

### 圖 2: 功能亮點圖 (Features)
**佈局：**
- 米白背景
- 左側：3-5 個功能點（勾號 + 文字）
- 右側：相關截圖
- 頂部小標：「What's Included」

**功能列表範例：**
- ✓ Automatic Calculations
- ✓ Visual Dashboard & Charts
- ✓ 15+ Expense Categories
- ✓ Mobile Friendly
- ✓ Print Ready

### 圖 3: Dashboard 截圖
**佈局：**
- 純白/淺灰背景
- 全屏 Dashboard 截圖
- 周圍加標註箭頭指向重點區域
- 小文字說明各區域功能

### 圖 4: 細節展示 (Detail Shots)
**佈局：**
- 2-3 個放大截圖拼貼
- 展示公式、圖表、條件格式等細節
- 每個截圖加圓角和陰影
- 配文字標籤說明

### 圖 5: 使用步驟 (How It Works)
**佈局：**
- 3 步驟橫排
- Step 1: Download → Step 2: Enter Data → Step 3: See Results
- 每步配一個小圖標和截圖
- 底部 CTA: 「Start Now — Instant Download」

### 圖 9: 套裝展示（套裝用）

- 標出單買總價 vs 套裝價
- 「Save XX%」標籤

### 圖 10: FAQ / 保證
- 常見問題列表
- 「Instant Download」「Lifetime Access」「Free Updates」圖標
- 增加購買信心

## Canva 模板建立建議

1. 先做一個「SheetCraft 主圖模板」
2. 複製修改給每個新產品（換截圖和文字即可）
3. 保持所有產品風格一致 → 建立品牌辨識度
4. 建議用 Canva Pro 的 Brand Kit 功能統一管理色彩和字體
