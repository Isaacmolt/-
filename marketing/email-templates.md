## 常見客服回覆模板

### 客戶問：如何在 Google Sheets 打開？
```
Great question! Here's how:

1. Go to sheets.google.com
2. Click the folder icon (Open File Picker)
3. Select "Upload" tab
4. Drag or browse for the .xlsx file you downloaded
5. It will open in Google Sheets with all formatting preserved!

Alternatively: Open Google Drive → Upload the file → Right-click → Open with Google Sheets

Let me know if you need any more help!
```

### 客戶問：可以自訂分類嗎？
```
Absolutely! All categories are fully customizable.

Just go to the "Categories" tab and change any category name
or budget amount. The formulas in the Dashboard will
automatically update to reflect your changes.

You can also add new categories by inserting a new row and
following the same format.

Enjoy! 😊
```
